# ONDERWERP : Autobedrijf shop

# FUNCTIONALITEIT

een autowinkel waar de gebruiker auto's kan opzoeken, filteren op merken/type auto ze willen. En als ze graag een auto willen, kunnen ze eentje kopen.

De user kan ook zelf een auto op verkoop gaan zetten op voorwaarde dat hij een account heeft.
Het opslaan van favoriete auto's kan ook enkel gedaan worden als een user een account heeft.
Een gebruiker kan ook dan een aankoop doen on de website met Mollie of Stripe. De user kan ook gegevens van de auto downloaden via een export knop voor elke listing.

Mogelijks een onderscheid gaan maken tussen verkopers en normale users, NOG TE ZIEN...

De admin heeft een overzicht van alle gebruikers, kan ook verwijderen en ook hun favorieten zien. De admin kan overzicht van de listingen en bij wie het hoort.
